# 📊 Retail Sales Performance Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard developed to analyze retail sales performance across stores, departments and store types. The project focuses on transforming retail data into meaningful business insights through data modeling, DAX and interactive visualizations.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

## Key Features
- Total Sales KPI monitoring
- Department-wise sales analysis
- Store-wise sales comparison
- Sales performance by store type (A, B and C)
- Sales trends over time
- Holiday-based sales analysis
- Interactive date-range filtering

## Data Preparation & Modeling
- Cleaned and transformed datasets using Power Query.
- Created relationships between Dim_store, fact_sales and Features tables.
- Developed DAX measures for sales calculations and KPI reporting.

## Business Objectives
- Monitor overall retail sales performance.
- Compare sales across stores and departments.
- Identify sales trends over time.
- Analyze sales patterns during holiday periods.
